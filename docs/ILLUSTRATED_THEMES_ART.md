# Illustrated theme artwork

Generated with the built-in imagegen tool. Each transparent mood atlas contains 36 drawings: nine 2×2 four-frame loops on a 6×6 grid. Moods in block order: joyful, calm, sad, affection, anxious, frustrated, surprised, neutral, invite. The app renders the atlas directly, preserving full alpha and pausing motion when requested by the OS.

Cards, calendar plates, search, profile plates, birthday tags and navigation are drawn by `QIllustratedSurface` so text remains live and surfaces grow with their contents. The generated backdrops and characters provide the raster artwork.

## Prompts

### retro / moods

Use case: illustration-story. Asset type: production transparent 2D animation sprite atlas for a Flutter journal app, Retro Postcard theme. Create ONE square 3072 x 3072 PNG with alpha transparency, exactly 6 columns by 6 rows of equally sized invisible cells (36 frames). No lines, no labels, no typography, no scenery outside individual sprites. This is a hand-inked 1960s travel-postcard mascot: a charming small terracotta-red fox with a cream muzzle, navy neckerchief, carrying a little mustard notebook. Flat limited gouache/screenprint colors, imperfect confident ink contours, warm restrained terracotta/mustard/teal palette, no 3D, no glossy anime, no gradients. Each sprite centered in its cell with a constant scale, complete silhouette, 18% transparent padding on every edge. Nine 2x2 animation blocks arranged 3 blocks across and 3 down. Each 2x2 block is one four-frame animation in local reading order top-left top-right bottom-left bottom-right. The blocks in reading order depict: 1 joyful (tiny happy bounce, eyes blink); 2 calm (quiet breath, notebook held close); 3 sad (droopy ears, gently wipes tear); 4 affection (hugs small heart); 5 anxious (fidgets notebook, nervous ears); 6 frustrated (arms crossed, tiny steam puff); 7 surprised (ears perk, eyes widen); 8 neutral (sits relaxed, blinks); 9 inviting (waves one paw beside open notebook). Within EACH block draw the SAME mascot in four subtly different successive key poses for a calm looping hand-drawn animation, with matching ground line and unchanging proportions. All 36 cells populated, transparent blank gutters, absolutely no text, checkerboard pattern, borders or background color.
